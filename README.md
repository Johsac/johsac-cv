# johsac-cv

Personal portfolio & CV website for **Johsac Isbac Gomez Sanchez** — PhD Researcher in Generative AI & LLMs at UNICAMP, Brazil.

## 🌐 Live Site

[https://johsac.github.io/johsac-cv/](https://johsac.github.io/johsac-cv/)

## ✨ Features

- **Light premium design** with glassmorphism cards, gradient accents, and micro-animations
- **Bilingual support** (English / Spanish) with one-click toggle
- **Animated timeline** for experience and education
- **Publications** with venue badges and DOI links
- **Featured projects** linked to GitHub repositories
- **Categorized skills** (GenAI/NLP, Core Tech, Data Science)
- **Language proficiency** with visual progress bars
- **Responsive** design for mobile, tablet, and desktop
- **PDF download** button for the traditional CV

## 🛠️ Tech Stack

- HTML5, CSS3 (vanilla), JavaScript (vanilla)
- Google Fonts (Inter, JetBrains Mono)
- Font Awesome icons
- GitHub Pages hosting
